# 智能烟感系统开发指南

## 🚨 开发前必读 🚨

**请所有开发者在开始开发前，务必仔细阅读以下技术方案文档：**

- **技术方案设计文档**：`develop_design_docs/02-架构设计/技术方案设计文档.md`
  - 包含系统架构、技术栈选型、功能模块设计、数据模型等核心信息
  - 定义了传感器协议、接口规范、报警处理逻辑等关键内容

## 开发流程

1. **阅读文档**：仔细阅读技术方案设计文档，理解系统架构和设计规范
2. **环境搭建**：参考后端和前端目录下的README.md搭建开发环境
3. **代码开发**：按照文档中的设计规范进行代码开发
4. **测试验证**：确保开发的功能符合文档中的需求和设计
5. **提交代码**：遵循项目的Git分支策略提交代码

## 技术栈

- **后端**：Spring Boot 2.5、MyBatis 3.5、Netty、MySQL 8.0、Redis
- **前端**：Vue 3.4、Element-plus 2.4、Echart
- **传感器**：JTY-GD-TCN2010智能烟感传感器（支持Cat.1通信）

## 注意事项

- 所有代码必须遵循文档中的接口规范和数据模型
- 传感器通信协议必须严格按照技术方案文档中的定义实现
- 报警处理逻辑必须符合文档中的报警类型与优先级设计
- 开发过程中如遇问题，请首先参考技术方案文档，确保理解设计意图
