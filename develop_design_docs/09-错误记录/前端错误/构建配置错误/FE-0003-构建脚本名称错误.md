# FE-0003-构建脚本名称错误

## 1. 错误基本信息

**错误类型**：前端错误 -> 构建配置错误
**严重程度**：中等
**影响范围**：构建流程
**记录时间**：2025-12-10 10:00:00
**解决时间**：2025-12-10 10:10:00
**记录人**：开发者
**解决人**：开发者

## 2. 错误描述

在执行前端构建命令时，使用了错误的脚本名称导致构建失败。

**错误信息**：
```
npm ERR! Missing script: 'build'
npm ERR! 
npm ERR! Did you mean this?
npm ERR!     build:prod
npm ERR!     build:stage
```

**触发条件**：
- 执行 `npm run build` 命令时
- 前端项目的 package.json 文件中没有定义 'build' 脚本

## 3. 错误分析

### 3.1 根因分析

- **直接原因**：执行了错误的构建命令 `npm run build`
- **根本原因**：package.json 中定义的构建脚本名称为 `build:prod` 和 `build:stage`，而不是通用的 `build`

### 3.2 影响评估

- 导致构建流程中断
- 影响开发效率
- 不影响已部署的应用

## 4. 解决方案

### 4.1 修复方案

使用正确的构建脚本名称 `npm run build:prod` 执行构建。

### 4.2 修复代码

**修改前**：
```bash
npm run build
```

**修改后**：
```bash
npm run build:prod
```

### 4.3 相关依赖

无

## 5. 验证结果

### 5.1 验证方法

执行 `npm run build:prod` 命令验证构建是否成功。

### 5.2 验证环境

- Node.js 版本：v16.13.0
- npm 版本：8.1.0
- 操作系统：Linux

### 5.3 验证结果

- 构建成功完成
- 生成了 dist 目录
- 无错误信息
