# BE-0022-测试框架模拟逻辑错误

## 1. 错误描述

- **错误标题**：测试框架中模拟逻辑错误导致测试失败
- **错误现象**：在`NotificationServiceTest`中，`testRechargeFreeVoiceQuota`和`testRechargeFreeSmsQuota`方法抛出断言错误和`UnnecessaryStubbingException`异常
- **发生环境**：
  - 操作系统版本：Linux
  - 系统版本号：智能烟感系统后端v1.0
- **复现步骤**：
  ```
  1. 运行`mvn test -Dtest=NotificationServiceTest`
  2. 观察测试结果，发现两个测试方法失败
  ```

## 2. 错误分析

- **错误定位**：
  - 文件路径：`/var/ctt_wkplace/iot/backend/src/test/java/com/iot/notification/service/impl/NotificationServiceTest.java`
  - 函数/方法名：`testRechargeFreeVoiceQuota`和`testRechargeFreeSmsQuota`
  - 行号：分别为155行和178行
- **错误日志**：
  - 断言错误：`expected: <true> but was: <false>`
  - 不必要的模拟错误：`UnnecessaryStubbingException`
- **可能原因**：
  - 测试中错误模拟了额度记录不存在的场景
  - 实际实现类会在额度记录不存在时自动创建默认额度
  - 测试验证了错误的Mapper方法（将`insertNotificationQuota`替换为实际调用的`addFreeVoiceQuota`和`addFreeSmsQuota`）
  - 测试中包含了不必要的设备服务模拟调用
- **影响范围**：
  - 影响的功能模块：通知额度管理模块
  - 影响的用户群体：开发人员
  - 影响的业务流程：单元测试流程

## 3. 解决方案

- **解决思路**：
  1. 将测试中的模拟逻辑从"额度记录不存在"改为"已有额度记录"
  2. 修改验证的Mapper方法为实际调用的方法
  3. 移除不必要的设备服务模拟调用

- **具体步骤**：
  1. 修改`testRechargeFreeVoiceQuota`方法：
     - 将`when(notificationQuotaMapper.selectNotificationQuotaBySensorId(anyString())).thenReturn(null);`改为`when(notificationQuotaMapper.selectNotificationQuotaBySensorId(anyString())).thenReturn(notificationQuota);`
     - 将`verify(notificationQuotaMapper, times(1)).insertNotificationQuota(any(NotificationQuota.class));`改为`verify(notificationQuotaMapper, times(1)).addFreeVoiceQuota(any(RechargeQuota.class));`
     - 移除设备服务相关的模拟代码
  2. 修改`testRechargeFreeSmsQuota`方法：
     - 执行与上述相同的修改

- **代码修改**：
  ```java
  // 错误的代码
  // 模拟额度记录不存在
  when(notificationQuotaMapper.selectNotificationQuotaBySensorId(anyString())).thenReturn(null);
  // 验证错误的方法
  verify(notificationQuotaMapper, times(1)).insertNotificationQuota(any(NotificationQuota.class));
  // 不必要的设备服务模拟
  Device device = new Device();
  device.setSensorId("sensor001");
  device.setStatus("1");
  when(deviceService.selectDeviceBySensorId(anyString())).thenReturn(device);

  // 修复后的代码
  // 模拟已有额度记录
  when(notificationQuotaMapper.selectNotificationQuotaBySensorId(anyString())).thenReturn(notificationQuota);
  // 验证正确的方法
  verify(notificationQuotaMapper, times(1)).addFreeVoiceQuota(any(RechargeQuota.class));
  ```

- **相关依赖**：无
