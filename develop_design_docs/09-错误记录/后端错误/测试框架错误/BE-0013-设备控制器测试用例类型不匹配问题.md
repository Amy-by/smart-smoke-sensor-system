# BE-0013-设备控制器测试用例类型不匹配问题

## 1. 错误描述

- **错误标题**：设备控制器测试用例类型不匹配问题
- **错误现象**：在运行DeviceControllerTest单元测试时，编译失败，提示"no suitable method found for thenReturn(long)"
- **发生环境**：
  - 操作系统版本：Linux
  - 系统版本号：1.0
- **复现步骤**：
  ```
  1. 进入项目根目录：cd /var/ctt_wkplace/iot/backend
  2. 运行测试：mvn test -Dtest=DeviceControllerTest
  3. 观察编译错误
  ```
- **错误截图**：无

## 2. 错误分析

- **错误定位**：
  - 文件路径：/var/ctt_wkplace/iot/backend/src/test/java/com/ruoyi/project/device/controller/DeviceControllerTest.java
  - 方法名：testGetTotalDeviceCount、testGetOnlineDeviceCount
  - 行号：285、302
- **错误日志**：
  ```
  [ERROR] /var/ctt_wkplace/iot/backend/src/test/java/com/ruoyi/project/device/controller/DeviceControllerTest.java:[285,50] no suitable method found for thenReturn(long)
  [ERROR]     method org.mockito.stubbing.OngoingStubbing.thenReturn(java.lang.Integer) is not applicable
  [ERROR]       (argument mismatch; long cannot be converted to java.lang.Integer)
  [ERROR] /var/ctt_wkplace/iot/backend/src/test/java/com/ruoyi/project/device/controller/DeviceControllerTest.java:[302,51] no suitable method found for thenReturn(long)
  ```
- **可能原因**：
  - 代码逻辑错误：在测试用例中使用了long类型的返回值，但DeviceService接口中的方法返回类型是Integer
  - 数据类型不匹配：Mockito框架无法将long类型自动转换为Integer类型
- **影响范围**：
  - 影响的功能模块：设备控制器测试模块
  - 影响的用户群体：开发人员
  - 影响的业务流程：单元测试执行流程

## 3. 解决方案

- **解决思路**：将测试用例中的long类型返回值改为Integer类型，与DeviceService接口中的方法返回类型保持一致
- **具体步骤**：
  1. 打开DeviceControllerTest.java文件
  2. 定位到testGetTotalDeviceCount方法
  3. 将when(deviceService.getTotalDeviceCount()).thenReturn(100L)改为when(deviceService.getTotalDeviceCount()).thenReturn(100)
  4. 定位到testGetOnlineDeviceCount方法
  5. 将when(deviceService.getOnlineDeviceCount()).thenReturn(80L)改为when(deviceService.getOnlineDeviceCount()).thenReturn(80)
  6. 保存文件并重新运行测试
- **代码修改**：
  ```java
  // 错误代码
  when(deviceService.getTotalDeviceCount()).thenReturn(100L);
  when(deviceService.getOnlineDeviceCount()).thenReturn(80L);
  
  // 修复后的代码
  when(deviceService.getTotalDeviceCount()).thenReturn(100);
  when(deviceService.getOnlineDeviceCount()).thenReturn(80);
  ```
- **相关依赖**：无
