# BE-001-Zigbee协议分隔符转义问题

## 1. 错误描述

### 错误标题
Zigbee协议适配器中管道符分隔符未正确转义导致数据解析错误

### 错误现象
在实现ZigbeeProtocolAdapter类时，使用split("|")方法解析管道符分隔的数据，但由于管道符在正则表达式中是特殊字符，导致数据被错误分割，所有测试用例均失败。

### 发生环境
- 操作系统：Linux
- 开发环境：IntelliJ IDEA
- Java版本：JDK 8+
- 项目框架：Spring Boot

### 复现步骤
1. 实现ZigbeeProtocolAdapter类，使用split("|")方法解析管道符分隔的数据
2. 编写单元测试，使用"123456789012345|50|25|80|2025-01-27 10:30:00"格式的数据进行测试
3. 运行测试，观察结果

### 错误截图
无

## 2. 错误分析

### 错误定位
- 文件路径：/var/ctt_wkplace/iot/backend/src/main/java/com/iot/protocol/adapter/ZigbeeProtocolAdapter.java
- 方法名：adapt
- 行号：约30行

### 错误日志
测试运行时抛出DataParseException，错误信息为"原始数据字段数量错误"

### 可能原因
- 管道符(|)在正则表达式中是特殊字符，表示"或"操作
- 使用split("|")会导致字符串被每个字符分割，而不是按管道符分割
- 正确的做法是使用转义字符或字符类来匹配管道符

### 影响范围
- 影响的功能模块：Zigbee协议适配器
- 影响的用户群体：所有使用Zigbee协议的传感器数据解析
- 影响的业务流程：传感器数据采集和处理流程

## 3. 解决方案

### 解决思路
- 将管道符正确转义，使用split("\\|")或split("[|")来匹配管道符
- 重新运行测试验证修复效果

### 具体步骤
1. 修改ZigbeeProtocolAdapter类中的split方法调用，将"|"改为"\\|"
2. 重新编译项目
3. 运行单元测试

### 代码修改
```java
// 错误代码
String[] fields = rawData.split("|");

// 修复后的代码
String[] fields = rawData.split("\\|");
```
