# BE-002-数据库初始化缺失

## 1. 错误描述
- 错误现象：admin用户在登录系统时，系统提示"用户不存在/密码错误"
- 发生环境：
  - 操作系统：Linux Ubuntu
  - 后端版本：若依框架3.9.0
  - 数据库：MySQL
- 复现步骤：
  1. 访问系统登录页面
  2. 输入正确的用户名和密码
  3. 点击登录按钮
  4. 观察到登录失败，提示"用户不存在/密码错误"

## 2. 错误分析
- 错误定位：数据库表结构和初始数据缺失
- 可能原因：
  - 数据库未创建或未初始化
  - 数据库表结构不存在
  - 初始用户数据未导入
- 影响范围：
  - 影响的功能模块：用户登录验证
  - 影响的用户群体：所有系统用户
  - 影响的业务流程：用户无法正常登录系统

## 3. 解决方案
- 解决思路：使用项目提供的SQL脚本初始化数据库
- 具体步骤：
  1. 确认数据库已创建
  2. 查找项目中的SQL初始化脚本
  3. 执行SQL脚本初始化数据库表结构和数据
- 代码修改：无
- 执行命令：
  ```bash
  mysql -h localhost -u root -pcc ry-vue < /var/ctt_wkplace/iot/backend/sql/ry_20250522.sql
  ```

## 4. 验证结果
- 验证方法：查看数据库表结构和admin用户数据
- 验证环境：与错误发生环境相同
- 验证结果：
  - 数据库表结构已创建
  - admin用户数据已导入
  - 用户登录验证能够正常进行
