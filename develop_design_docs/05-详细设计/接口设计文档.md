# 接口设计文档

## 1 文档说明
**说明**：本文档详细描述智能烟感系统的RESTful接口设计，包含接口路径、请求方法、参数、响应格式和示例，确保接口设计清晰、规范统一。

## 2 通用规范要求
- **RESTful风格**：遵循RESTful设计规范，使用标准HTTP方法（GET、POST、PUT、DELETE）
- **接口定义清晰**：接口路径、参数、响应格式明确
- **参数验证规范**：所有入参必须进行验证，包含必填项、格式、范围等校验
- **统一响应格式**：所有接口使用统一的响应格式

## 3 统一响应格式

### 3.1 成功响应
```json
{
  "code": 200,
  "msg": "操作成功",
  "data": {
    // 业务数据
  }
}
```

### 3.2 失败响应
```json
{
  "code": 500,
  "msg": "错误信息",
  "data": null
}
```

## 4 设备管理接口

### 4.1 设备注册
- **接口路径**：`POST /api/iot/device/register`
- **功能描述**：注册新的传感器设备
- **请求参数**：
```json
{
  "deviceId": "IMEI号",
  "deviceType": "设备类型",
  "deviceName": "设备名称",
  "protocolType": "协议类型（CAT1/ZIGBEE/WIFI）"
}
```
- **响应示例**：
```json
{
  "code": 200,
  "msg": "设备注册成功",
  "data": {
    "deviceId": "IMEI号",
    "deviceName": "设备名称",
    "status": "ONLINE"
  }
}
```

### 4.2 设备列表查询
- **接口路径**：`GET /api/iot/device/list`
- **功能描述**：分页查询设备列表
- **请求参数**：
  - pageNum: 页码（必填）
  - pageSize: 每页数量（必填）
  - deviceId: 设备ID（可选）
  - status: 设备状态（可选）
- **响应示例**：
```json
{
  "code": 200,
  "msg": "查询成功",
  "data": {
    "total": 100,
    "list": [
      {
        "deviceId": "IMEI号",
        "deviceName": "设备名称",
        "status": "ONLINE",
        "lastReportTime": "2025-01-27 10:00:00"
      }
    ]
  }
}
```

### 4.3 设备绑定
- **接口路径**：`POST /api/iot/device/bind`
- **功能描述**：绑定设备到用户或位置
- **请求参数**：
```json
{
  "deviceId": "设备ID",
  "userId": "用户ID",
  "location": "安装位置"
}
```

## 5 报警处理接口

### 5.1 报警列表查询
- **接口路径**：`GET /api/iot/alarm/list`
- **功能描述**：分页查询报警列表
- **请求参数**：
  - pageNum: 页码（必填）

- **响应示例**：
```json
{
  "code": 200,
  "msg": "查询成功",
  "data": {
    "total": 50,
    "list": [
      {
        "alarmId": "报警ID",
        "deviceId": "设备ID",
        "alarmType": "火灾",
        "alarmLevel": "紧急",
        "alarmTime": "2025-01-27 10:00:00",
        "description": "报警描述"
      }
    ]
  }
}
```

## 6 通知管理接口

### 6.1 发送通知
- **接口路径**：`POST /api/iot/notification/send`
- **功能描述**：发送通知（短信/语音/APP推送）
- **请求参数**：
```json
{
  "deviceId": "设备ID",
  "channelType": "通知渠道（SMS/VOICE/APP）",
  "recipient": "接收人",
  "templateId": "模板ID",
  "params": {
    "deviceName": "设备名称",
    "alarmType": "报警类型"
  }
}
```

### 6.2 通知记录查询
- **接口路径**：`GET /api/iot/notification/list`
- **功能描述**：查询通知发送记录
- **请求参数**：
  - pageNum: 页码（必填）
  - pageSize: 每页数量（必填）
  - deviceId: 设备ID（可选）
  - channelType: 通知渠道（可选）

## 7 数据日志接口

### 7.1 传感器数据查询
- **接口路径**：`GET /api/iot/sensor-data/list`
- **功能描述**：查询传感器历史数据
- **请求参数**：
  - pageNum: 页码（必填）
  - pageSize: 每页数量（必填）
  - deviceId: 设备ID（必填）
  - startTime: 开始时间（可选）
  - endTime: 结束时间（可选）

### 7.2 数据统计
- **接口路径**：`GET /api/iot/sensor-data/statistics`
- **功能描述**：获取传感器数据统计信息
- **请求参数**：
  - deviceId: 设备ID（必填）
  - startTime: 开始时间（必填）
  - endTime: 结束时间（必填）
  - statisticsType: 统计类型（AVG/MAX/MIN）

## 8 接口安全规范

### 8.1 认证机制
- 所有接口需要携带Token进行认证
- Token通过登录接口获取
- Token过期时间：24小时

### 8.2 权限控制
- 基于角色的权限控制（RBAC）
- 接口级别权限验证
- 数据级别权限过滤

### 8.3 参数验证
- 所有必填参数必须验证
- 参数格式验证（类型、长度、范围）
- 参数安全验证（SQL注入、XSS防护）
